# Data directory

The scripts read their inputs from this directory. The repository ships code only, so these
files are not included; obtain or generate them as described below and place them here with the
exact names listed.

## Expected files

| File | Contents | How to obtain |
|---|---|---|
| `features_13ch.tif` | 13-band feature raster, 30 m, float32; marine cells are nodata | Build in Google Earth Engine from the public indicator sources; apply 2%–98% robust normalization and a consistent "higher is more trafficable" direction |
| `label_3class.tif` | Single-band three-class label (values 0/1/2) | Derive from a continuous AHP score using `data_utils.make_label_from_ahp` |
| `soil_physical_raw_30m.tif` | Seven physical soil bands: SAND, SILT, CLAY, BD, SOC, W33, TEX | Export from OpenLandMap; the GEE script `export_soil_physical_raw.js` performs this step |
| `mech_RCI_30m.tif` | Continuous rated cone index raster | Generated by `soil/build_mech_label.py` |
| `mech_label_3class.tif` | Three-class mechanistic label | Generated by `soil/build_mech_label.py` |
| `common_domain.npz` | Common-domain tiles for both labels | Generated by `analysis/prep_common_domain.py` |
| `real_data.npz`, `real_data_full.npz` | Real-data training patches and grid references | Generated by the data-preparation scripts |
| `gee_raw/` | Raw downloaded GEE tiles before merging | Input to the soil merge/reproject scripts |

The thirteen feature bands, in order, are:

```
NLI, NBD, NCLAY, NSAL, NAI, NSI, NCUR, NDW, NWDI, NSAR, NLST, NVFI, NLULC
```

## Sources

- Google Earth Engine remote-sensing collections and the public OpenLandMap soil product.
- The mechanistic label is produced entirely from the OpenLandMap physical bands under the
  Bekker–Wong model; it is not an in-situ measurement.

## Restricted material

Third-party engineering-geological maps, borehole compilations and rock-mass strength grades are
not redistributed. They are used only as indirect corroboration and must be requested from the
original holding organization.

## Redirecting the location

The default location is this repository-relative `data/` folder. Set the `TRAFFIC_DATA`
environment variable to point elsewhere; no code edits are required.
